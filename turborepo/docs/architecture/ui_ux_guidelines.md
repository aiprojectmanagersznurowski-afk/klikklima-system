# UI/UX Guidelines

## Technology Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Component Library:** Shadcn UI
- **Icons:** `lucide-react`
- **Forms:** `react-hook-form` + `@hookform/resolvers/zod` + `zod`

## Styling Rules
- **Brand Colors:** The primary brand color is `blue-600` (to be confirmed).
- **Spacing/Layout:** Use standard Tailwind spacing metrics. Tables must occupy full width. Sidebars should be collapsible.
- **Microinteractions:** Use `framer-motion` for complex animations, or simple Tailwind `transition-all` for hover states.
